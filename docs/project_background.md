# Project Background

Author: Özay Kocak

Kojak Street began from a long-standing personal interest in economics,
politics, history, financial markets, macroeconomics and monetary systems.

Özay Kocak trained as a banker and worked for several years in banking,
including customer service and advisory work across savings, building-society
products, securities, loans and private-client banking.

The project started as a small broker-terminal trading game with a simple
macro simulation. Through iterative development it became a broader financial
simulation system with supply chains, macro drivers, companies, bonds,
derivatives, portfolio risk, tests and a modern desktop UI.

## Development Approach

The project was built autodidactically through learning by doing, feedback
from software-developer friends, self-study and practical use of LLMs as
development assistants.

LLMs were used for architecture planning, feature decomposition, code
generation, refactoring, debugging, test design, documentation and reviewing
model logic. The financial ideas, product direction, feature priorities and
final decisions were driven by Özay Kocak.

## Learning Outcomes

Through Kojak Street, the project author learned how to turn a broad financial
idea into a working software system. The work built practical skills in
Python, object-oriented programming, Visual Studio Code, project structure,
testing, debugging and iterative optimization.

The project also provided practical experience in using LLMs as planning,
research, coding, refactoring and UI-design partners while keeping ownership
of the product direction and model assumptions.

## What The Project Demonstrates

- practical banking background applied to a software project
- self-directed learning and persistence over a long development process
- ability to translate financial intuition into executable models
- responsible use of LLMs as development support
- working software with tests, documentation and model limitations
- a bridge between finance, product thinking and engineering
