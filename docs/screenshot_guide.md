# Screenshot Guide

Use these screenshots for the GitHub README, LinkedIn posts and applications.
The goal is to show a professional financial terminal and prove that the
simulation has connected mechanics.

Save screenshots in a future `screenshots/` folder with the suggested names
below.

## Required Screenshots

### 1. Main Terminal / Markets

File name:

```text
screenshots/01_markets_overview.png
```

Capture:

- full application window
- Markets view
- table, filters and right-side chart panel visible
- ideally after several simulated months so changes are visible

Why it matters:

- first visual impression
- shows the broker-terminal concept immediately
- works well as the top README image

### 2. Asset Detail With Drivers

File name:

```text
screenshots/02_asset_detail_drivers.png
```

Capture:

- a stock, commodity, crypto or derivative detail page
- chart visible
- KPI/drivers area visible
- for derivatives, a CDS detail page is useful because it shows use case and
  pricing note

Why it matters:

- shows that assets are not just rows in a table
- highlights explainability and model transparency

### 3. Supply Chain

File name:

```text
screenshots/03_supply_chain.png
```

Capture:

- Supply Chain view
- sort or filter by imbalance/pressure
- product rows with produced, demanded, inventories, balance and pressure

Why it matters:

- proves the simulation has a real-economy layer
- makes the project more distinctive than a normal trading game

### 4. Supply-Chain Detail

File name:

```text
screenshots/04_supply_chain_detail.png
```

Capture:

- selected product detail
- produced/demanded charts visible
- country production share chart visible

Why it matters:

- shows charts, time series and regional production logic

### 5. Macro Dashboard

File name:

```text
screenshots/05_macro_dashboard.png
```

Capture:

- Macro view
- KPI row visible
- country table visible with growth, rates, inflation, unemployment and rating

Why it matters:

- shows the model's macroeconomic foundation
- relevant for banking, risk and consulting applications

### 6. Bond Market

File name:

```text
screenshots/06_bond_market.png
```

Capture:

- Bond Market view
- yields, duration, rating, price and default risk visible
- if possible, include both government and corporate examples

Why it matters:

- shows fixed-income and credit-risk understanding
- important for financial-services credibility

### 7. Portfolio

File name:

```text
screenshots/07_portfolio_overview.png
```

Capture:

- Portfolio view
- KPI row visible
- positions or bonds tab visible
- ideally with at least one position so PnL/exposure is meaningful

Why it matters:

- shows the broker/accounting side of the system
- connects simulation output to portfolio consequences

### 8. Test Result

File name:

```text
screenshots/08_tests_passed.png
```

Capture:

- terminal output showing `226 passed`
- crop cleanly so root path and result are visible

Why it matters:

- demonstrates engineering discipline
- useful in a README section about verification

## Screenshot Quality Rules

- Use a clean 16:9 desktop window where possible.
- Avoid tiny cropped details as the main README image.
- Advance the simulation before taking screenshots so the charts and changes
  look alive.
- Do not show private desktop folders or unrelated windows.
- Prefer readable tables over dramatic cropping.
- Use PNG format.
